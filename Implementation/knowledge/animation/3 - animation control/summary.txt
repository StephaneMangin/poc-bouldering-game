Contrôle des animations avec Unity Animator Controller et booléens
Cette vidéo, présentée par Mickey, fait partie d’une série dédiée à l’apprentissage du système d’animation d’Unity. Elle se concentre sur l’utilisation du Animator Controller, en particulier sur la gestion des transitions entre états d’animation via des paramètres booléens.

Concepts clés abordés
Animator Controller : composant central permettant de gérer les états d’animation et leurs transitions.
Paramètres dans l’Animator : quatre types disponibles pour contrôler les transitions :
Float : nombre à virgule flottante.
Int : nombre entier.
Bool : valeur booléenne (true/false).
Trigger : booléen avec un traitement spécifique dans Unity.
Transitions entre états d’animation : connexions entre animations définies par des conditions basées sur les paramètres.

Réglages avancés des transitions
Option de transition	Description
Mute	Désactive complètement la transition, empêchant le changement d’animation via celle-ci.
Solo	Ne joue que cette transition, bloquant toutes les autres transitions simultanées.
Transition Duration	Durée du mélange entre deux animations, influence la fluidité (0 = transition instantanée).
Transition Offset	Position de départ dans l’animation cible, exprimée en valeur normalisée (0 à 1).
Interruption	Permet de changer d’animation en cours de transition seulement si la condition est respectée.
Exemple d’interruption : si on passe de Idle à Walk et qu’on veut passer rapidement à Run pendant la transition, l’interruption doit être configurée sur Next State.
La configuration Current State impose de terminer la transition en cours avant de changer d’état.
Conclusions principales
Le contrôle des animations via booléens dans l’Animator Controller est simple et efficace pour gérer des états comme l’Idle, la marche et la course.
Les transitions peuvent être affinées avec des réglages de durée, d’interruption et d’offset pour améliorer la fluidité.
L’intégration par script permet une interaction dynamique avec les entrées utilisateur, rendant les animations réactives.
L’optimisation du code en évitant les appels redondants et en utilisant les hash d’Unity améliore les performances.
